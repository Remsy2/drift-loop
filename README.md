# DRIFT LOOP — browser prototype

Play: https://remsy2.github.io/drift-loop/ · One-pager: https://remsy2.github.io/drift-loop/onepager.html

Arcade time trials with collectible toy sports cars on desk-top circuits. Drift to wind a hidden spring, release it as a boost, and beat your own ghost.
Built with Unity 6 (URP, WebGL). Asset credits: asset-credits.md · Font licence: font-license.txt
