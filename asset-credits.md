# Материалы DRIFT LOOP

- Модель GT-27 строится в игре по видам машины, предоставленным автором проекта. Синий R-08 использует тот же кузов.
- Эталонный кадр графики предоставлен автором проекта как художественный ориентир.
- Записи двигателя: domasx2, треки `loop_3.wav` и `loop_5.wav` из [Racing car engine sound loops](https://opengameart.org/content/racing-car-engine-sound-loops), CC0.
- Музыка: MintoDog, [Racing Game Title](https://opengameart.org/content/racing-game-title) для меню и [Hot Roadway](https://opengameart.org/content/hot-roadway) для заезда, обе CC0.
- Montserrat используется по SIL Open Font License 1.1. Текст лицензии поставляется в `font-license.txt` вместе с браузерной сборкой.
